# FastAPI 请求处理流程图

## 一、总体请求处理流程

```mermaid
graph TD
    A[客户端发送 HTTP POST 请求] --> B[FastAPI 接收请求]
    B --> C[路由匹配 URL Path]
    C --> D{匹配到哪个接口?}

    D -->|/v1/text-cls/regex| E1[regex_classify]
    D -->|/v1/text-cls/tfidf| E2[tfidf_classify]
    D -->|/v1/text-cls/bert| E3[bert_classify]
    D -->|/v1/text-cls/gpt| E4[gpt_classify]

    E1 --> F[Pydantic 自动校验请求体 TextClassifyRequest]
    E2 --> F
    E3 --> F
    E4 --> F

    F --> G{校验是否通过?}
    G -->|失败| H[返回 422 Validation Error]
    G -->|成功| I[记录 start_time]

    I --> J[初始化 TextClassifyResponse 空壳对象]
    J --> K[logger.info 记录请求日志]
    K --> L[try: 调用对应 model_for_xxx 推理函数]

    L --> M{推理是否成功?}
    M -->|成功| N[classify_result = 分类结果]
    M -->|异常| O[classify_result = 空字符串]

    N --> P[error_msg = ok]
    O --> Q[error_msg = traceback 完整堆栈]

    P --> R[计算 classify_time = 当前时间 - start_time]
    Q --> R

    R --> S[FastAPI 自动将 Pydantic 对象序列化为 JSON]
    S --> T[返回 HTTP 200 + JSON 响应体]
```

## 二、Pydantic 数据校验细节

```mermaid
graph TD
    A[收到 JSON 请求体] --> B[FastAPI 解析 JSON]
    B --> C[映射到 TextClassifyRequest 模型]

    C --> D{request_id 字段}
    D -->|缺失| E[使用默认值 None]
    D -->|存在| F[校验为 Optional str]

    C --> G{request_text 字段}
    G -->|缺失| H[返回 422 错误: field required]
    G -->|是 str| I[校验通过]
    G -->|是 List str| J[校验通过]
    G -->|其他类型| K[返回 422 错误: type error]

    I --> L[构造 TextClassifyRequest 实例]
    J --> L
    F --> L
    E --> L
    L --> M[传入路由处理函数]
```

## 三、四种模型推理内部流程

### 3.1 正则规则匹配 (model_for_regex)

```mermaid
graph TD
    A[接收 request_text] --> B{输入类型?}
    B -->|str| C[遍历所有预编译正则规则]
    B -->|list| D[遍历列表中每条文本]
    B -->|其他| E[抛出异常: 格式不支持]

    C --> F[对每个类别执行 regex.findall]
    F --> G{是否匹配到关键词?}
    G -->|是| H[将该类别加入结果列表]
    G -->|否| I[跳过]
    H --> J{所有类别遍历完?}
    I --> J
    J -->|否| F
    J -->|是| K{结果列表是否为空?}
    K -->|是| L[添加 Other]
    K -->|否| M[返回分类结果]
    L --> M

    D --> N[对每条文本重复上述匹配逻辑]
    N --> M
```

### 3.2 TF-IDF + SVM (model_for_tfidf)

```mermaid
graph TD
    A[接收 request_text] --> B{输入类型?}
    B -->|str| C[jieba.lcut 中文分词]
    B -->|list| D[对每条文本分别分词]
    B -->|其他| E[抛出异常]

    C --> F[过滤停用词 cn_stopwords]
    D --> F
    F --> G[空格拼接为字符串]
    G --> H[tfidf.transform 向量化]
    H --> I[model.predict SVM 预测]
    I --> J[返回分类标签列表]
```

### 3.3 BERT 深度学习 (model_for_bert)

```mermaid
graph TD
    A[接收 request_text] --> B{输入类型?}
    B -->|str| C[包装为单元素列表]
    B -->|list| D[直接使用]
    B -->|其他| E[抛出异常]

    C --> F[tokenizer 编码: truncation + padding + max_length=30]
    D --> F
    F --> G[构建 NewsDataset]
    G --> H[构建 DataLoader batch_size=16]
    H --> I[model.eval 切换推理模式]
    I --> J[遍历 batch]
    J --> K[torch.no_grad 关闭梯度]
    K --> L[输入 input_ids + attention_mask 到 BERT]
    L --> M[获取 logits 输出]
    M --> N[np.argmax 取最大概率类别索引]
    N --> O[CATEGORY_NAME 映射为类别名称]
    O --> P[返回分类结果列表]
```

### 3.4 LLM + Few-shot Prompt (model_for_gpt)

```mermaid
graph TD
    A[接收 request_text] --> B{输入类型?}
    B -->|str| C[tfidf.transform 单条向量化]
    B -->|list| D[tfidf.transform 批量向量化]
    B -->|其他| E[抛出异常]

    C --> F[遍历每条待分类文本]
    D --> F
    F --> G[计算与训练集的 TF-IDF 相似度]
    G --> H[取 Top10 最相似样本]
    H --> I[拼装动态 Few-shot 示例字符串]
    I --> J[填充 PROMPT_TEMPLATE 模板]
    J --> K[调用 OpenAI 兼容 API]
    K --> L[提取 response.choices 0 .message.content]
    L --> M[追加到结果列表]
    M --> N{还有下一条?}
    N -->|是| F
    N -->|否| O[返回分类结果列表]
```

## 四、服务启动与模型预加载流程

```mermaid
graph TD
    A[执行 uvicorn main:app] --> B[Python 解释器加载 main.py]
    B --> C[import 触发各模块初始化]

    C --> D[加载 config.py 全局配置]
    C --> E[加载 data_schema.py Pydantic 模型]
    C --> F[加载 logger.py 日志配置]

    C --> G[加载 model/regex_rule.py]
    G --> G1[预编译所有正则表达式 re.compile]

    C --> H[加载 model/tfidf_ml.py]
    H --> H1[joblib.load 加载 tfidf + SVM 模型]
    H --> H2[加载停用词表]

    C --> I[加载 model/bert.py]
    I --> I1[AutoTokenizer.from_pretrained 加载分词器]
    I --> I2[BertForSequenceClassification 加载模型结构]
    I --> I3[load_state_dict 加载微调权重]
    I --> I4[model.to device 转移到 GPU/CPU]

    C --> J[加载 model/prompt.py]
    J --> J1[读取训练数据集 dataset.csv]
    J --> J2[加载 TF-IDF 向量化器]
    J --> J3[计算全量训练集 TF-IDF 特征矩阵]
    J --> J4[初始化 OpenAI Client]

    D --> K[FastAPI app 实例创建完成]
    E --> K
    F --> K
    G1 --> K
    H1 --> K
    H2 --> K
    I4 --> K
    J4 --> K
    K --> L[服务就绪，开始监听端口 8000]
```

## 五、完整请求生命周期（端到端）

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant FastAPI as FastAPI 框架
    participant Pydantic as Pydantic 校验
    participant Handler as 路由处理函数
    participant Model as 模型推理层
    participant Logger as 日志模块

    Client->>FastAPI: POST /v1/text-cls/tfidf
    Note over Client,FastAPI: Content-Type: application/json

    FastAPI->>FastAPI: 路由匹配 URL Path
    FastAPI->>Pydantic: 解析 JSON Body
    Pydantic->>Pydantic: 校验 request_id, request_text
    Pydantic-->>FastAPI: 返回 TextClassifyRequest 实例

    FastAPI->>Handler: 调用 tfidf_classify(req)
    Handler->>Handler: start_time = time.time()
    Handler->>Handler: 初始化 TextClassifyResponse
    Handler->>Logger: logger.info 记录请求

    Handler->>Model: model_for_tfidf(request_text)
    Model->>Model: jieba 分词
    Model->>Model: 停用词过滤
    Model->>Model: TF-IDF 向量化
    Model->>Model: SVM 预测
    Model-->>Handler: 返回分类结果

    Handler->>Handler: 计算 classify_time
    Handler-->>FastAPI: 返回 TextClassifyResponse

    FastAPI->>FastAPI: Pydantic 序列化为 JSON
    FastAPI-->>Client: HTTP 200 + JSON Response
```
